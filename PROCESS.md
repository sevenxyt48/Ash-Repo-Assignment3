# Process

## Tools

- **Doubao**: Used during the early-stage brainstorming phase for conceptualizing the single-page layout structure and defining core relationship filters (Word Origins, Similar Meanings, Easily Confused, Antonyms).
- **ChatGPT**: Used for code architecture and logic development, specifically structuring the JSON dataset, implementing the linear relationship graph layout, and writing smooth spring-physics micro-animations.
- **Gemini**: Used for drafting the project's markdown documentation (`README.md` and `PROCESS.md`), structuring the technical and user guides, and ensuring clarity.

## Kept

- **Automatic Initial Word Initialization**: Kept Doubao's suggestion to automatically display an initial starter word (e.g., “水”) with its relationship graph upon first entry. This was kept because it eliminates friction and allows users to experience the interactive graph instantly without needing to search first.

## Rejected

- **Gamified Streaks & Pop-up Quizzes**: Rejected Doubao's suggestion to add daily streaks, score counters, and quiz modules. This was rejected because the core intent of the project is a calm, open-ended vocabulary exploration tool rather than a test-driven language learning course.
